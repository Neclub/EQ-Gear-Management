```text
Create a modern Windows desktop application in C# using WPF and MVVM named:

"EQ Achievement Tracker"

Purpose:
This application parses EverQuest achievement and collection log data and generates an Excel workbook that is easy to filter, sort, and understand.

The application should focus heavily on:
- Missing collection items
- Achievement progression
- Expansion tracking
- Zone tracking
- Character progression
- Excel export

====================================================
TECH STACK
====================================================

Requirements:
- Language: C#
- UI Framework: WPF
- Architecture: MVVM
- Database: SQLite
- Excel Library: ClosedXML
- .NET Version: .NET 8
- Use async/await where appropriate
- Use clean project structure and separation of concerns

NuGet Packages:
- ClosedXML
- Microsoft.Data.Sqlite
- CommunityToolkit.Mvvm

====================================================
APPLICATION FEATURES
====================================================

MAIN FEATURES:
1. Parse EverQuest log files
2. Detect achievement completions
3. Detect collection item acquisitions
4. Track missing collection items
5. Store parsed data in SQLite
6. Display sortable/filterable grids
7. Export fully formatted Excel workbook
8. Support multiple characters
9. Track expansion and zone progression
10. Provide dashboard statistics

====================================================
LOG PARSING
====================================================

The parser should monitor and import EverQuest log files.

Examples of achievement lines:

[Tue May 26 20:41:11 2026] You have completed the achievement 'Bristlebane Opens'!

Examples of collection item lines:

[Tue May 26 20:45:32 2026] You have collected: Cracked Sun Idol

Examples of collection completion:

[Tue May 26 20:48:11 2026] You have completed the collection: Ancient Relics

The parser should:
- Extract timestamp
- Extract character name from filename if possible
- Detect event type
- Normalize data
- Store data in SQLite
```
