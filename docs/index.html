EQ Gear Management

A Windows program for EverQuest Live that reads team inventory dumps and builds one report you can open in Excel or your browser — gear, tiers, runes, spells, achievements, augs, and Raid BiS.

EverQuest Live only (not TLP or progression). Tracking goes back to Laurion’s Song. Windows 10/11 — no Python install needed.

What the report shows

Generate Excel, HTML, or both. The HTML report opens in your browser and is easy to search and filter.

Team Gear

Equipped items by slot for the whole team. Item names are color-coded by gear tier so outdated pieces stand out at a glance.

Gear T-Level

Same layout as Team Gear, but shows tier codes per slot (for example SOR-R2) instead of item names.

Unmade Gear

Raid craft mats and T1 containers still sitting in bags — visible even when that slot is already geared.

Missing Runes & Spells

Who still needs spell runes, which spells are missing, and which of those are the most useful ones to prioritize.

Rune Inventory

Raid runes already on hand in bags, bank, or shared bank across the roster.

Collections, Quests & Achievements

Incomplete collections, Mercenary/Partisan quests, and raid achievement progress — with checklists in the HTML report. Collection zone comes from a (Zone) suffix or a {Zone} Scavenger grouping; click a missing item name to copy it.

Type 7/8 Augs

Suggested type 7/8 augs to wear or farm, filtered to holes that can take them. When an aug should move to another slot, Upgrade to lists the replacement for the hole it leaves.

Type 5 Augs

Display of equipped type 5 augs and empty holes, with expansion and heroic stats. Preference only — no upgrade suggestions.

Raid BiS

Current-expansion raid T1/T2 armor and jewelry vs what you wear. HTML paperdoll (green = already BiS, gold = upgrade), waist belt choice, and raid-coin Best Purchase. Evolvers still show a BiS pick but are skipped for coin spending.

HTML Report

The same data in a searchable, filterable browser page with character filters and links out to EQ Resource.

How to use

In-game output commands, then generate the report in EQGM.

1. In EverQuest

  1. Log into each character you want in the report.
  2. Run in chat:
    /outputfile inventory
    /outputfile missingspells
    /outputfile achievements
  3. Optional, for a persona inventory: /outputfile inventory CHR_Server-CLASS-Inventory.txt. A hotkey per persona is suggested.

Inventory is required. Missing spells and achievements add extra report sections.

2. In EQGM

  1. Download EQGM-x.y.z.exe from Releases and open it.
  2. Click EQ Folder, pick your EverQuest Logs folder, and select characters.
  3. Choose Excel, HTML, or Both, then click Generate Report.

Installed copies can check for updates when they open, or via Help → Check for Updates.
