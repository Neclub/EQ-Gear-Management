===== MESSAGE 1: PURPOSE =====
# EQ Gear Management (EQGM)
### What it is

A Windows program for **EverQuest Live** players.
-# Not for TLP or progression servers.

EverQuest can save a snapshot of a character as a text file. EQGM reads those files for everyone on your team and builds **one report** you can open in Excel or in your web browser.

**Use it to answer questions like:**
> ⚔️ Who is wearing what?
> 📉 Whose gear is outdated?
> 📜 Who still needs spell runes?
> 🏆 Who is missing collections, quests, or raid achievements?
> 🗺️ What should people farm next?

You do **not** need to install anything extra. Download the program, double-click it, and follow the How to Use posts.

### Download
🔗 https://github.com/Neclub/EQ-Gear-Management/releases

Get the file named `EQGM-x.y.z.exe`
-# The numbers change with each version. Works on Windows 10 and 11.

===== MESSAGE 2: FUNCTIONS =====
# What the report shows

After you generate a report, you get an **Excel** file, a **web page**, or both. The web page opens in your browser and is easy to search.

### 🛡️ Team Gear
A grid of everyone on the team. Each row is a gear slot. Item names are color-coded:
> 🟢 **Green** — newest raid gear
> 🟡 **Yellow** — close
> 🟠 **Orange** — last expansion
> 🔴 **Red** — older
> 🟣 **Purple** — Evolver

### 📊 Gear T-Level
Same layout, but shows the tier name instead of the item name (for example `SOR-R2`).

### ⚒️ Unmade Gear
Craft materials and T1 containers still sitting in bags — listed so you know they are there, even if that slot is already geared.

### 📘 Missing Runes / Spells / Useful Spells
Who still needs spell runes, which spells they are missing, and which of those spells are the most useful ones.

### 🎒 Rune Inventory
Raid runes people already have in bags or bank.

### 🏆 Collections, Quests, Raid Achievements
What is still incomplete. For collections, you can also see who on the team already has the item. The Zone column uses a `(Zone)` suffix on the collection name, or a `{Zone} Scavenger` grouping. In the web report, click a missing item name to copy it.

### 💎 Type 7/8 Augs
Suggested augs to wear or farm. The web report shows an inventory paperdoll of aug icons on each character’s Slot recommendations card. If an aug should move to another slot, Upgrade to shows what replaces it. Hover **Slot recommendations** for a reminder that these are suggestions. **Need** / **Have** Focus chips open EQ Resource.

### 💠 Type 5 Augs
Shows which type 5 augs people already have equipped (and empty holes), with an inventory paperdoll of aug icons in the web report. Preference only — no upgrade suggestions.

### 👑 Raid BiS
Compares what you are wearing to this expansion’s raid armor and jewelry.

Enter raid coins on each character card to highlight the best vendor upgrade. Evolvers still get a Best in slot pick, but that slot is skipped when spending coins.

-# Current raid gear only. Hover **Raid BiS** in the web report for the scoring notes.

Clicking an item name opens **EQ Resource** for more info.

===== MESSAGE 3: HOW TO USE (IN EVERQUEST) =====
# How to use — Part 1
### In EverQuest

Do this on **each character** you want in the report.

**1.** Log into the character in EverQuest.

**2.** Type these commands in chat, one at a time, and press Enter:
> `/outputfile inventory`
> `/outputfile missingspells`
> `/outputfile achievements`

-# Optional for **Personas**. It is suggested to make a hotkey for each persona.
> `/outputfile inventory CHR_Server-CLASS-Inventory.txt`

> ⚠️ The first command is **required**. The other two are optional, but they add extra pages to the report (spells, runes, collections, quests, achievements).

**3.** EverQuest saves text files in your **EverQuest Logs** folder.

That’s all you do in-game.
-# Next post: using the program.

===== MESSAGE 4: HOW TO USE (THE PROGRAM) =====
# How to use — Part 2
### The program

**1.** Download `EQGM-x.y.z.exe` from:
🔗 https://github.com/Neclub/EQ-Gear-Management/releases

**2.** Double-click the file to open it.

**3.** Click **EQ Folder** and choose your **EverQuest Logs** folder.

**4.** Check the characters you want, then click **Add selected**.
-# If you play on more than one server, use the **Server** dropdown first.

**5.** The left side lists who will be in the report. Drag a name to move it; a gap shows where it will land. You can also use **Up** or **Down**.
-# The first name becomes the first column.

**6.** On the right, leave the extra options on unless you want a smaller report:
> 📜 **Spells** — runes and missing spells
> 🏆 **Achievements** — collections, quests, raid progress
> 💎 **Type 7/8 Augs** — aug suggestions
> 💠 **Type 5 Augs** — equipped type 5 augs (display only)
> 👑 **Raid BiS** — best-in-slot raid gear comparison

**7.** Choose **Excel**, **HTML** (web page), or **Both**.
-# **HTML** is fine for most people.

**8.** Click **Generate Report**.
> 📁 Saved in **Downloads** as `{Server}_Team Inventory.xlsx` by default (or `{Character}_Team Inventory.xlsx` if you exported only one). Use **Browse…** under **Output folder** to pick a different folder; the file name stays the default.
> 🌐 If you chose HTML, it should open in your browser automatically.
