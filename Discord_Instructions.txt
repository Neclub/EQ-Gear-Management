**EQ Gear Management (EQGM) — Quick Guide**

Turn EQ inventory dumps into one Excel team workbook (gear, tier levels, unmade craft mats, optional missing rune tracking, optional achievement collection progress, optional Type 7/8 aug recommendations). Optionally generate an interactive HTML report in the same folder.

---

**In-game (per character)**
```
/outputfile inventory
/outputfile missingspells
/outputfile achievements
```
Copy the `.txt` files from your EQ Logs folder into one raid folder.

**File names**
• Inventory (required): `CharacterName_server-Inventory.txt`
  Example: `Deflub_bristle-Inventory.txt`
• Personas (optional): `CharacterName_server-CLASS-Inventory.txt` — one file per class/persona
  Example: `Deflub_bristle-PAL-Inventory.txt` (pairs with matching MissingSpells; ignores the generic inventory when present)
• Missing spells (optional): `CharacterName_server-CLASS-MissingSpells.txt`
  Example: `Healub_bristle-CLR-MissingSpells.txt`
• Achievements (optional): `CharacterName_server-Achievements.txt`
  Example: `Shamlub_xegony-Achievements.txt`

Tip: put spell files in a `SpellData` subfolder — the app groups them with the right character.
Tip: put achievement files in an `AchievementData` subfolder — same pattern.

---

**Download the app**
• Latest build: https://github.com/Neclub/EQ-Gear-Management/releases
• Download **`EQGM-x.y.z.exe`** — no Python install needed

**Using the app (EXE)**
1. Double-click **`EQGM-<version>.exe`**
2. Click **EQ Folder** and pick your dump folder
   • Check the characters you want
   • Use the **Server** dropdown to filter (e.g. Xegony)
   • Click **Add selected**
3. **Team characters** — the list shows toon names, not file paths
   • **Up** / **Down** to put your main or tank in the first column
   • Order is remembered for next time
4. (Optional) Leave **Spells** checked for rune tabs (auto-enabled when spell files are present)
5. (Optional) Leave **Achievements** checked for collection/summary tabs (auto-enabled when achievement files are present)
6. (Optional) Leave **Type 7/8 Augs** checked (on by default) for type 7/8 BiS / farm sheets; uncheck to skip the catalog fetch
   • When on, optional **Include Anniversary augs** (Gems of Distant Echoes) and **Advanced weights** for a single-character roster
7. Choose **Excel** / **HTML** / **Both** next to **Generate Report** (default **Both**; remembered next time)
8. Click **Generate Report**

Default save location: `Downloads\{Server}_Team Inventory.xlsx`
Use **Browse…** to pick a different path if you want.

---

**What you get (Excel)**
• **Team Gear** — who is wearing what (tier-bucket colors: green / yellow / orange / red / purple)
• **Gear T-Level** — tier codes per slot (`SOR-R2`, `TOB-R2`, etc.)
• **Unmade Gear** — craft mats and T1 containers in General bags that still upgrade a slot
• **Missing Runes** — Rk. III rune totals by spell expansion (LS / ToB / SoR); one matrix per expansion
• **Missing Spells** — every missing Rk. III with level, rune tier, expansion, and spell name
  • Missing Rk. II at levels 121–130 counts too (shown as Rk. III in the report)
• **Missing Useful Spells** — curated useful spells still missing (Raccoo’s list × your MissingSpells dump; all levels)
• **Rune Inventory** — on-hand raid runes in bags/bank (NoS, LS, ToB, SoR); no spell file needed
• **Missing Collections / Achievement Summary / Raid Achievements** — when achievement dumps are included (once per character; personas share achievements/collections)
• **Type 7/8 Augs** — type 7/8 recommendations, Need to Farm, ranked list (when the Type 7/8 Augs chip is on; uses a catalog fetch + cache)

Item names link to EQ Resource when the dump has item IDs.

**HTML report (optional)** — same data in a single `.html` file beside the Excel workbook (`{Server}_Team_Inventory.html`). Open in any browser; no server needed.

• **Sidebar** — Lucide-style section icons (Team Gear, Gear T-Level, Missing Runes, Missing Spells, Missing Useful Spells, Rune Inventory, Unmade Gear, Type 7/8 Augs, …)
• **Character filter** chips under the nav — multi-select by toon/persona (All clears; personas labeled when shared)
• **Search**, **sort** (click headers), **Visible slots** on gear tabs (search keeps focus while typing)
• **Character** / **Rune type** / **Expansion** dropdowns on table tabs (Missing Spells, Missing Useful Spells, Raid Achievements, Rune Inventory, etc.)
• **Expansion** on achievement tabs defaults to the current expansion (not All) — change the dropdown to see older content
• Gear colors and EQ Resource links match Excel

---

**Quick tips**
• You need at least one `*-Inventory.txt` — spell files alone aren't enough
• First character in the list = first column in Excel and HTML (reorder with **Up** / **Down**)
• Close the Excel file before exporting if save fails
• Regenerate the HTML after app updates to pick up layout changes
• **Help** (top right) → gear tier colors and About EQGM
• No Python install needed — just run the `.exe`
