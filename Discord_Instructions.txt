**Inventory Parser — Quick Guide**

Turn EQ inventory dumps into one Excel crew workbook (gear, tier levels, optional missing rune tracking, optional achievement collection progress). Optionally generate an interactive HTML report in the same folder.

---

**In-game (per character)**
```
/outputfile inventory
/outputfile missingspells
/outputfile achievements
```
Copy the `.txt` files from your EQ Logs folder into one raid folder.

**File names**
• Inventory (required): `CharacterName_server-Inventory.txt`
  Example: `Deflub_bristle-Inventory.txt`
• Missing spells (optional): `CharacterName_server-CLASS-MissingSpells.txt`
  Example: `Healub_bristle-CLR-MissingSpells.txt`
• Achievements (optional): `CharacterName_server-Achievements.txt`
  Example: `Shamlub_xegony-Achievements.txt`

Tip: put spell files in a `SpellData` subfolder — the app groups them with the right character.
Tip: put achievement files in an `AchievementData` subfolder — same pattern.

---

**Using the app (EXE)**
1. Double-click **`InventoryParser.exe`**
2. Click **Add folder…** and pick your dump folder
   • Check the characters you want
   • Use the **Server** dropdown to filter (e.g. Xegony)
   • Click **Add selected**
3. **Crew characters (column order)** — the list shows toon names, not file paths
   • **Move up** / **Move down** to put your main or tank in the first column
   • Order is remembered for next time
4. (Optional) Leave **Include missing spells** checked for rune tabs
5. (Optional) Leave **Include achievements** checked for collection/summary tabs
6. (Optional) Check **Also generate HTML report** for a browser-viewable `.html` file next to the Excel workbook
7. Click **Generate Excel**

Default save location: `Downloads\{Server}_Crew Inventory.xlsx`
Use **Browse…** to pick a different path if you want.

---

**What you get**
• **Crew gear** — who is wearing what (color-coded by gear set)
• **Gear T-Level** — tier codes per slot (`SOR-R2`, `TOB-R2`, etc.)
• **Unmade Gear** — craft mats and T1 containers in General bags that still upgrade a slot
• **Missing Runes / Spell List** — missing Rk. III runes (121–125 & 126–130)
  • Missing Rk. II at those levels counts too (shown as Rk. III in the report)
• **Missing Collections / Achievement Summary** — incomplete collection items and per-section completion counts (when achievement dumps are included)

Item names link to EQ Resource when the dump has item IDs.

**HTML report (optional)** — same data in a single `.html` file you open in a browser; tabs, search, sort, and expansion filters built in. Saved as `{Server}_Crew Inventory.html` beside the Excel file.

---

**Quick tips**
• You need at least one `*-Inventory.txt` — spell files alone aren't enough
• First character in the list = first column in Excel and HTML (reorder with **Move up** / **Move down**)
• Close the Excel file before exporting if save fails
• **Help → Gear tiers & slots** in the app explains colors and slot layout
• No Python install needed — just run the `.exe`
